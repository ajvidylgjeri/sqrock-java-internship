# Online Banking System (Java)

Console banking application — Sqrock IT Solutions Java Internship, Phase 1 Task 1.

## Features
- Create account (Savings/Current) with auto-generated account number
- Secure login with password
- Deposit, withdraw (with overdraft protection), and transfer between accounts
- Transaction history per account
- Admin view of all accounts
- Data persisted to `accounts.txt` and `transactions.txt`

## Run
```bash
javac BankingSystem.java
java BankingSystem
```

## Concepts
Core Java · OOP · collections (`LinkedHashMap`) · file I/O · input validation.
