# Online Quiz Application (Java)

Console quiz engine — Sqrock IT Solutions Java Internship, Phase 1 Task 2.

## Features
- Multiple-choice questions with 4 options each
- Category selection (Java, Web, Database, General) or "All"
- Randomised questions, 5 per attempt
- Per-question soft timer (~20s)
- Instant scoring, percentage, grade and a review of wrong answers
- Persistent leaderboard (`scores.txt`)
- Question bank auto-seeds to `questions.txt` on first run (editable)

## Run
```bash
javac QuizApp.java
java QuizApp
```

## Concepts
Core Java · OOP · collections · file I/O · randomisation · timing.
