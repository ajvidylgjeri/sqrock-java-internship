# Sqrock IT Solutions — Java Internship (Phase 1)

Console applications built with **Core Java**, demonstrating OOP, collections and file handling. Three projects completed (the phase requires any 3).

| # | Project | Folder | Highlights |
|---|---------|--------|-----------|
| 1 | Online Banking System | [`online-banking-system`](./online-banking-system) | Accounts, deposit/withdraw/transfer, transaction history, file persistence |
| 2 | Online Quiz Application | [`online-quiz-application`](./online-quiz-application) | MCQ engine, categories, per-question timer, scoring, leaderboard |
| 3 | Job Portal System | [`job-portal-system`](./job-portal-system) | Role-based (candidate/employer), post & apply for jobs, search, file persistence |

## 🛠️ Requirements
- JDK 8 or later (developed on JDK 21)

## 🚀 Run any project
```bash
cd online-banking-system      # or another project folder
javac *.java
java BankingSystem            # QuizApp / JobPortal for the others
```
Each program is menu-driven and stores its data in local text files, so state persists between runs.

## 📚 Concepts demonstrated
Core Java · OOP (classes, encapsulation) · Collections (List, Map) · File I/O (read/write/append) · Input validation · Exception handling
