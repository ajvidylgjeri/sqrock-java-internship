# Job Portal System (Java)

Console job portal — Sqrock IT Solutions Java Internship, Phase 1 Task 3.

## Features
- Two roles: **Candidate** and **Employer**
- Candidates: view all jobs, search by keyword, apply (no duplicate applications), view their applications
- Employers: post jobs, view their postings, see applicants per job, delete jobs
- Seed jobs provided; all jobs and applications persisted to `jobs.txt` / `applications.txt`

## Run
```bash
javac JobPortal.java
java JobPortal
```

## Concepts
Core Java · OOP · role-based flow · collections · file I/O · search/filter.
